# SpecuLoop System

SpecuLoop is the overall system built on top of WRAP and DRAG.

## Components

- **WRAP**: persistent semantic graph
- **DRAG**: dynamic retrieval with semantic zoom
- **Translation**: bidirectional Mumble ↔ WRAP
- **Extension**: self-extending knowledge structures
- **Feedback**: human correction propagation
- **Persistence**: graph serialization

## Intended Capabilities

1. Persistent semantic memory across sessions
2. Semantic zoom for context-efficient reasoning
3. Lens-dependent multi-view retrieval
4. Interlocked translation (natural language ↔ code)
5. Human-in-the-loop feedback
6. Self-extending knowledge graph
7. Reality-constrained reasoning (failures become knowledge)
8. Multi-agent shared memory
