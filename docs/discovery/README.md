# Discovery Log

External projects, papers, and algorithms related to SpecuLoop's core concepts.

When a new external resource is found that solves a related problem, document:

1. What it does
2. What problem it solves
3. What SpecuLoop shares
4. What differs
5. What we might learn from it
6. Whether we should adopt anything

---

## Log Entries

Entries are added as new resources are discovered. This becomes a persistent part of the project's semantic memory.
